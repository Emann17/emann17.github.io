# Emmanuel Odubela — Portfolio

Personal website for Emmanuel (Ope) Odubela, Computer Software Engineering student at the University of Alberta.

**Live site:** https://emann17.github.io

## What's on it

- Projects, with links to the source on GitHub
- Work experience and certifications
- Skills and a short about section
- Contact details and a downloadable resume

## Built with

Plain HTML, CSS and JavaScript — no frameworks or build step. Hosted on GitHub Pages.

## Running locally

Clone the repo and open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

then visit http://localhost:8000.
